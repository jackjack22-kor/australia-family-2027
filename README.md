# 우리 가족의 호주 여름 · 2027

모바일 우선 여행 현황판입니다. 단일 index.html에 CSS·JavaScript·표지 사진·여행 데이터를 포함합니다.

## 기능

여행안·귀국 도시 비교, 날짜별 지도·숙소·명소, 항공·숙소 예약 기록, 비용 비교, 준비사항, 메모, 백업·복원·인쇄를 지원합니다.

## 저장

현재는 기기별 브라우저 localStorage에 저장합니다. 웹사이트 배포만으로 기기 간 체크리스트·메모가 동기화되지는 않습니다. 관리에서 JSON 백업·가져오기를 사용하세요.

공개 파일에는 실제 예약번호와 개인 입력 스냅샷을 넣지 않았습니다. 입력한 예약번호와 메모는 해당 브라우저에만 저장됩니다. 백업·HTML 사본을 공개 저장소에 올리지 마세요.

## 배포

GitHub 저장소 Settings → Pages → Deploy from a branch → main / (root)에서 배포합니다. index.html과 .nojekyll을 루트에 둡니다.

## 수정

index.html의 const TRIP 객체에서 plans는 여행안, days는 날짜별 일정, hotels는 숙소, flights는 항공편, tasks는 준비사항입니다. 코드 수정 후 같은 파일을 갱신하면 됩니다. 공개 저장소에 예약번호를 직접 입력하지 마세요.

## 검증 및 출처

원본 계산기는 여섯 일정 조합의 박수·연속 날짜·귀국 변형·비용, 날짜별 호텔 예약 상태, 화면 생성 검사를 통과했습니다. 실제 모바일 화면 검수는 배포 후 진행합니다.
